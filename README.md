# コンブゲーム

30秒で昆布全体を傷め、5人を同時に逃がすスマホ向け海中アクション。

## 遊び方

- タップで各人の昆布をねじる。タップそのものにはダメージなし。
- 最大ねじりは約3秒保持し、ゆっくり緩む。ドラッグは移動に使い、ねじりを自動で補充しない。
- ドラッグ／フリックで昆布同士を当てると、全体共通の耐久力が減る。
- 片方だけねじっていても効く。接触した双方のねじれの相乗効果と、5人の平均ねじれ量によるボーナスがある。
- 1人だけのタップ連打ではクリアできない。みんなをねじってから交差させると効率がよい。
- 胴体同士の衝突は跳ね返りだけ。ドラッグ終了後約0.65秒でダメージ受付を止め、放置で進まない。
- HUDの「コンブのダメージ」が100%になると全5本が同時に切れ、全員が泡を残して泳ぎ去る。2.4秒の脱出演出後に結果を表示。
- 時間切れは人魚の捕獲演出後に敗北。新ルールの端末ベストは `konbu-team30-best-v1` に保存。

## 音

BGMは魔王魂の提供音源。通常SEは添付の「水中で息を吐く1・2・3」を順に使用し、重なりすぎないよう再生数を制限。
クリア時は添付の男衆「イヤッホー！」を一度再生し、通常SEとBGMを止めて聞こえやすくする。
音ボタンはBGM・SE・ファンファーレ共通。詳細は AUDIO-SOURCES.md。

## 開発・確認

HTML/CSS/JavaScript、Canvas 2D。GitHub Pagesで公開。以前のキャラスプライトを使用。

`node --check game.js`、`node check-game.cjs`、`git diff --check`。
テスト対象は30秒の時間切れ、タップ連打の無効性、ねじれによる接触ダメージ差、ねじり保持、全員同時脱出、泳ぎ演出、ファンファーレの一回再生、放置、入力キャンセル、音源の切替と消音。
モックテストと縦画面Canvas描画は、実機の操作感・音の聴感・性能を保証しない。
