# ワカメ脱出

つつく。のばす。ぎゅルルン！ 60秒で5人を救出する、スマホ向けの海中アクション。

## 操作とゲームデザイン

- タップ：自分のワカメにねじりをためる。限界で高速逆回転して耐久力を削る。
- ドラッグ／フリック：伸ばして離し、別のワカメと絡ませる。ためたねじりが多いほど衝突の威力と反動が大きい。
- 胴体の接触は跳ね返りだけ。ダメージのボーナスはワカメの接触で発生する。
- タップだけでもクリア可能。絡みを狙えると複数を一度に削れる。
- 両端は少し切れやすく、大振りの反動も強い。残り2人から補助、最後の1人はタップ数回で仕上げられる。
- 手を止めると連鎖は収まり、放置中に自動で削れ続けない。速い操作で制限時間が短くなるペナルティはない。
- 正面／横／背面スプライトに伸縮、傾き、回転線を加えた2D描画。帯の局所変形で絡みを表現し、厳密な布物理や3Dモデルは使用しない。
- 泡、差し込む光、人魚の影、結果の遊び方別カウント、端末内ベスト、任意の共有ボタン。

## 音

初期設定はWeb Audioで合成する112 BPMの軽いマリンバ風ループと泡／回転／反動のSE。音楽ボタンで元の添付BGM・BGMなしへ切替。右のボタンで全消音。
元の添付BGM：「ぴょこぴょこダンス / Hopping Popping Dance」蒲鉾さちこ。添付SEの元アセットは保持。

## 開発・確認

依存ライブラリなし。GitHub Pagesで直接公開可能。

`node --check game.js` と `node check-game.cjs` で構文、放置時の失敗、タップのみの全員脱出、最後の1人、ワカメ交差、入力キャンセルを確認。
シミュレーションは操作ルールの確認用。スマホ実機での触り心地・音の好み・描画負荷は別途プレイして調整する。
