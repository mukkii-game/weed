# ワカメ脱出

スマホのフリックとタップで、1本ずつの太い平帯状ワカメに捕まった5人の丸い生き物をじたばたさせて脱出する物理アクションゲームです。

## 遊び方

- 左右・上下フリックで振り子運動と回転を起こします。
- 逆方向へタイミングよくフリックすると反動が増します。
- 1人だけでも揺れとねじれで少しずつ耐久値を減らせます。
- 複数のワカメを衝突・交差させて逆回転すると、大きな摩擦ダメージになります。
- 周囲にも負荷が伝わるため、5人の耐久値を揃えて全員脱出させるのが理想です。
- タップ連打でもじたばたできる片手向け操作です。
- 回転に合わせてキャラクターの正面・横・背中が切り替わります。
- ねじれは上端から下へ伝わり、強く操作すると何回転ものツイストになります。
- ワカメ同士の衝突で帯が折れ、キャラクターが反対方向へ回り、水の衝撃輪が出ます。
- 制限時間が近づくと巨大な人魚の影が迫ります。
- BGM「ぴょこぴょこダンス」とミュートボタンを搭載しています。
- 逆回転・衝突・切断・泳いで脱出・人魚に捕まる場面に専用SEがあります。

BGM: 「ぴょこぴょこダンス / Hopping Popping Dance」蒲鉾さちこ
