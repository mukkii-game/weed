# コンブゲーム

30秒で昆布全体を傷め、5人を同時に逃がすスマホ向け海中アクション。

共有HPは910に戻し、5人で連携して約30秒以内に削り切る調整にしている。

## 遊び方

- タップでそのキャラの昆布をねじる。タップした左右の向きでねじり方向が変わり、タップそのものにはダメージなし。
- 複数の指で別々のキャラを同時にタップすると、全員が動き出すマルチタップ補助が入り、急いだ協力プレイほど接触を作りやすい。
- 最大ねじりは約3秒保持し、ゆっくり緩む。ドラッグは移動に使い、ねじりを自動で補充しない。
- ドラッグはつかんだキャラをその方向へ連続移動させる。フリックは指を離した瞬間の方向・速さで弾き、別の昆布へ当てる。横方向は隣へ交差、縦方向は上下にずらして交差を作る。
- ドラッグ／フリックで昆布同士を当てると、全体共通の耐久力が減る。
- 片方だけねじっていても効く。接触した双方のねじれの相乗効果と、5人の平均ねじれ量によるボーナスがある。
- 1人だけのタップ連打ではクリアできない。みんなをねじってから交差させると効率がよい。
- 胴体同士の衝突は跳ね返りだけ。ドラッグ終了後約0.65秒でダメージ受付を止め、放置で進まない。
- キャラの下に残り秒数を常時大きく表示し、10秒以下で黄色〜赤に点滅する。「コンブのHP」は画面幅いっぱいの太い緑ゲージで、ダメージを受けるほど右から赤い部分が増える。残り1/3以下では緑の部分が黄色く点滅する。
- HUDの「コンブのHP」が0になると全5本が切れ、1.5秒かけて四方八方へ回転しながら破片が飛び散る。その後、全員が速度を半分にして横回転しながら画面端へ泳ぎ出す。時間と人魚の接近はその瞬間に止まり、脱出演出後は今回の秒数・この端末の最短・「もうひと暴れ！」だけを表示。
- 時間切れは人魚の捕獲演出後に敗北。新ルールの端末ベストは `konbu-team30-best-v1` に保存。

## 音

BGMは魔王魂の提供音源。通常SEは添付の「水中で息を吐く1・2・3」を順に使用し、重なりすぎないよう再生数を制限。
脱出時は水中SEを重ね、クリア時は添付の男衆「イヤッホー！」を5つ少しずつずらして重ね、通常SEとBGMを止めて聞こえやすくする。BGMはSEが聞き取りやすいよう音量を抑えている。
開始時は男声「オーッ！」、0.5秒後に歓声。ねじりMAXでは「締め付ける1」、高威力の昆布接触では「ナイフで突き刺す2／3」をランダム再生する。
捕食時は「噛みつく」を半速で3回続けて再生し、人魚が大きく口を開ける演出を重ねる。
音ボタンはBGM・SE・ファンファーレ共通。詳細は AUDIO-SOURCES.md。

## 開発・確認

HTML/CSS/JavaScript、Canvas 2D。GitHub Pagesで公開。キャラ差し替え用に `assets/sea-friend-sprites-template.png`（900×300、正面／横／背面の3コマ）を用意。ゲーム本体はこの絵を色替えした7方向スプライト（正面・斜め4方向・横・背面）を使用している。

ビルド: `npm ci && npm run build`（成果物は `dist/`、`dist/index.html` が入口。参照はサブパス対応の相対パス）。

`node --check game.js`、`node check-game.cjs`、`git diff --check`。
テスト対象は30秒の時間切れ、タップ連打の無効性、ねじれによる接触ダメージ差、ねじり保持、全員同時脱出、2秒の霧散演出、時間停止、ファンファーレの一回再生、放置、入力キャンセル、音源の切替と消音。
モックテストと縦画面Canvas描画は、実機の操作感・音の聴感・性能を保証しない。
